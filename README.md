# AptKogMatrix - Offline-First Local Data Analytics Engine

AptKogMatrix is a premium, secure, and offline-first Local Data Analytics Engine. It uses a decoupled architecture with a FastAPI backend running multi-threaded Polars data queries, Scikit-Learn clustering, and LangChain semantic assistance, paired with a clean Streamlit interactive UI.

## Features
- **Data Ingestion**: Multi-file excel upload with sheet-nested tab navigation.
- **Universal Filter Engine**: 15+ comparison operators powered by Polars.
- **Dynamic Pivot Engine**: Multidimensional index groupings and value aggregation.
- **Vectorized Dataset Builder**: Local VLOOKUP and join operations.
- **Skeleton Loading Screens**: Smooth placeholder screens for long running operations.
- **100% Offline and Secure**: Runs completely locally inside your browser container.
