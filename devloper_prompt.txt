## Task 2: Backend API Implementation (FastAPI)

Write the Python code for the Backend API. It must expose the following structural modules via endpoints:

1. Data Ingestion (`/api/upload`): Accepts up to 10 `.xlsx` files (max 500MB each). Parses metadata, file names, and sheet names. Saves files to a secure local temp directory.
2. Universal Filter Engine (`/api/filter`): Accepts a JSON payload containing data filters. Must implement at least 15 distinct comparison operators (`=`, `!=`, `Like`, `Contains`, `Starts With`, `Ends With`, `reg_expr`, `Wildcards`, `>`, `<`, `>=`, `<=`, `Is Null`, `Is Not Null`) mapped to Polars syntax. Returns metrics (`total_records` vs `filtered_records`) and JSON data payloads for Table, Graph, and Tree views.
3. Dynamic Pivot Engine (`/api/pivot`): Executes user-defined aggregations (Sum, Mean, Count, Max, Min) on Polars dataframes based on row indices, column groupings, and values.
4. Vectorized Dataset Builder (`/api/join`): Simulates VLOOKUP / INDEX-MATCH relational joins across separate uploaded files. Returns a downloadable binary stream of the consolidated Excel file.
5. Infrastructure Diagnostics (`/api/diagnostics`): Uses `psutil` and system checks to return real-time local RAM consumption (MB), CPU usage %, active Python compiler state, and Polars SIMD optimization status.
